桌宠设置

所有改动会自动保存 ✓

LLM 对话

启用后，右键聊天会调用大模型回复；关闭则使用内置台词。

长期记忆

两层记忆：共享层跨所有角色（基础信息、人际、长期偏好等），角色层由每个角色 pet.config.json 的 memoryFocus 决定关注什么。一次 LLM 提取同时产出两类，token 成本和单层一致。

桌宠日记

每天一篇日记，由桌宠用她的视角写。包含心情 emoji，可在日历中翻阅历史。

口袋图鉴

从长期记忆中提取实体（人物/宠物/食物/地点等），整理成卡片图鉴。每张卡片附带相关对话片段。

语音

部分角色（如小埋）自带配音，会在动作时随机播放。在角色 pet.config.json 里设 voiceEnabled: true 才会启用。

角色性格

每个角色的对话人设（system prompt）。改完自动保存，下次和该角色聊天时立即生效。

高级配置（缩放、窗口尺寸、台词库等）仍在 models/<角色>/pet.config.json 文件里手改。本设置只覆盖 personality 和 memoryFocus 两项。

数据管理

导出 / 重置 %APPDATA%\desktop-pet-live2d\ 下的所有用户数据（记忆 / 日记 / 塔罗 / 图鉴 / 待办 / 纪念日 / 设置）。换电脑时先导出再到新机器手动放进 APPDATA。
